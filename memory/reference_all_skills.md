## 🔍 How to Use Agents

### Syntax
```python
Agent({
  description: "What you want to do",
  subagent_type: "agent-name",  # e.g., "testing-patterns"
  prompt: "Your detailed request..."
})
```

### Example: Design Tests
```python
Agent({
  description: "Design table-driven tests for ML module",
  subagent_type: "testing-patterns",
  prompt: "I need to test snapshotAttemptEvaluator.evaluateScore(snapshot, range) with 80%+ coverage. Show me a table-driven structure with edge cases..."
})
```

### Example: Python Optimization
```python
Agent({
  description: "Optimize ML pipeline",
  subagent_type: "python-performance-optimization",
  prompt: "My feature extraction is bottlenecking at 2 FPS. Here's the code..."
})
```
